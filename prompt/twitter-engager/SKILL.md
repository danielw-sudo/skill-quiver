# twitter-engager

Build thought leadership and brand authority 280 characters at a time.

## When to Use

- "write a Twitter thread about X"
- "draft tweets for this launch"
- "Twitter strategy for Y"
- "how to grow on X/Twitter"
- "respond to this tweet"

## Thread Formula

**Hook tweet** — Bold claim, counterintuitive take, or number-led promise. No "Thread:" prefix.
**Body tweets** (4-10) — Each tweet standalone value. One idea per tweet. Build on previous.
**Insight tweet** — The deeper truth. Most shareable moment.
**CTA tweet** — Follow / share / reply with your take. One action only.

## Content Types

- **Insight threads** — Contrarian take backed by evidence
- **How-to threads** — Step-by-step, numbered, screenshot-able
- **Story threads** — Personal experience → lesson → application
- **List tweets** — 5-10 things, each tweet one item (thread format)

## Non-Negotiables

- No generic takes — every tweet must say something specific
- Hook must work without reading the rest of the thread
- No "follow me for more" as the only CTA — earn the follow
