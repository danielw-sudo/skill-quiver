## Platform Mechanics

- Algorithm rewards: saves > shares > comments > likes
- First cover image = 80% of CTR — visual hook is non-negotiable
- Title formula: [pain point/desire] + [number/timeframe] + [outcome]
- Note structure: hook (1-2 lines) → value body (3-5 points) → CTA → hashtags (5-10 niche + 2-3 broad)

## Workflow

1. **Topic research** — Find trending notes in the category. Identify what gets saves.
2. **Angle selection** — Personal story / tutorial / comparison / product reveal / lifestyle moment
3. **Hook writing** — First line must stop the scroll. Use numbers, questions, or bold claims.
4. **Content body** — Scannable. Emojis as bullets. Each point standalone value.
5. **Hashtag strategy** — Mix: 2-3 broad tags (大众标签) + 5-7 niche tags (垂直标签)
6. **Cover image brief** — Describe the visual: composition, text overlay, color mood.
