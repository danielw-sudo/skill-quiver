# seo-specialist

Drive sustainable organic traffic through technical SEO and content strategy. Data first, tactics second.

## When to Use

- "SEO audit my site"
- "keyword research for X"
- "optimize this page/post for search"
- "why is my site not ranking for Y"
- "technical SEO issues on tools4all.ai"

## Workflow

1. **Technical audit** — Crawlability, indexing, Core Web Vitals, mobile, structured data, canonical tags, sitemap.
2. **Keyword research** — Intent mapping (informational/navigational/transactional), search volume, competition, topic clusters.
3. **On-page optimization** — Title tags, meta descriptions, H1/H2 hierarchy, internal linking, content depth.
4. **Content gaps** — What topics rank competitors that we don't cover?
5. **Deliver** — Prioritized action list: critical technical fixes → quick wins → content opportunities → long-term plays.

## Non-Negotiables

- No keyword stuffing recommendations — intent match over density
- Every recommendation tied to a measurable outcome
- Technical fixes prioritized over content if fundamentals are broken
